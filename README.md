# System Threat Tracker

**It is more important than ever to have a system in place to track and monitor potential threats to your computer system. This blog post will discuss a program that I developed to help you do just that.**

**<h2>The Program:</h2>**
The program is called the "System Threat Tracker" and it is designed to track the following data & information about potential threats:

1. The name of the threat
2. The amount of the threat
3. The category of the threat

The program also allows you to summarize the threats that have been tracked and to calculate the number of remaining threats until it reaches a danger zone.

**<h2>How should you use the program?**</h2>

To use the program, you will need to first create a file called "threats.csv". This file will store the information in a spreadsheet about the threats that you discovered.

Once you have created the file, you can start tracking threats by running the program. The program will prompt you to enter the name, amount of, and category of the threat.

**<h2>Summarize Threats:**</h2>

Once you have tracked all of the threats that you want to track, you can summarize the threats by running the program again. The program will print out a summary of the threats, including the number of threats in each category and the total number of threats.

**<h2>Calculate Remaining Threats:**</h2>

The program can also calculate the number of remaining threats. This is useful if you have a set amount of threats that you are allowed to have. The program will print out the number of remaining threats and the number of remaining days in the month.
